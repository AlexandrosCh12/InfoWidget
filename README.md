# InfoWidget

A real-time desktop information widget for Windows, built for active traders and people who want fast, actionable news at a glance — without opening a browser.

---

## What It Does

InfoWidget sits on your desktop like a phone widget. It fetches live news every 5 minutes, filters it based on your personal interests, and uses AI to generate a specific actionable insight for every article — telling you what to watch for or act on, not just what happened.

**Core features:**
- Live news feed filtered by your interests (Markets, Crypto, Sports, Politics and more)
- AI-powered "Why This Matters" insight for every article, generated by Groq (Llama 3)
- Compact always-on-screen widget and full expanded feed view
- Click any article to read the full story in your browser
- Settings panel to change interests, widget size, theme and position
- Minimizes to system tray — out of your way until you need it
- Auto-refreshes every 5 minutes with no interaction needed

## Tech Stack

| Layer | Technology |
|---|---|
| Desktop shell | Tauri v2 (Rust) |
| Frontend | React 18 + TypeScript + Vite |
| Styling | Tailwind CSS + Framer Motion |
| Global state | Zustand |
| News data | NewsAPI via a secured Node.js backend |
| AI insights | Groq API (Llama 3.1 8B Instant) |
| Backend hosting | Railway |

## Architecture

The Tauri app never calls NewsAPI directly. All news requests go through a secured Node.js backend deployed on Railway. This bypasses NewsAPI's localhost-only restriction on the free plan and keeps the API key off the client.

## Running Locally

### Prerequisites
- Node.js v18+
- Rust
- Tauri CLI prerequisites for Windows

### 1. Clone the repo
```bash
git clone https://github.com/AlexandrosCh12/infowidget.git
cd infowidget
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables
Create a `.env` file in the project root:
VITE_API_BASE_URL=http://localhost:3001
VITE_GROQ_API_KEY=your_groq_api_key_here

### 4. Run the backend locally
```bash
git clone https://github.com/AlexandrosCh12/infowidget-backend.git
cd infowidget-backend
npm install
npm start
```

### 5. Run in development
```bash
npm run tauri dev
```

### 6. Build the installer
```bash
npm run tauri build
```

## Backend

The backend is a separate repository:
https://github.com/AlexandrosCh12/infowidget-backend

A secured Express.js server that:
- Proxies requests to NewsAPI
- Validates and sanitizes all query parameters
- Applies rate limiting (60 requests per 15 minutes per IP)
- Restricts CORS to known Tauri origins only
- Deployed on Railway free tier

## Environment Variables

### Tauri app (.env)
| Variable | Description |
|---|---|
| VITE_API_BASE_URL | URL of your deployed backend |
| VITE_GROQ_API_KEY | Groq API key for AI insights |

### Backend (.env)
| Variable | Description |
|---|---|
| NEWS_API_KEY | Your NewsAPI key |
| PORT | Server port (default 3001) |
